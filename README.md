# CampusCycle

An Inter-College Resource Sharing and Redistribution Platform.

## Overview

CampusCycle connects colleges and educational institutions to facilitate sharing, exchanging, donating and redistributing surplus educational resources.

## Problem Statement

Educational institutions often have unused resources while other institutions face shortages.

CampusCycle provides a centralized platform to discover, request, approve and transfer these resources.

## Core Features

- User Authentication
- College Profiles
- Resource Marketplace
- Resource Listing Management
- Request and Approval System
- Inventory Management
- Transfer and Delivery Tracking
- Analytics Dashboard
